Running Galaxy tools from a chat thread

Two clickable mock-ups of the same RNA-seq thread, to compare the current "Galaxy Runs Through Chat" spec with the changes we propose. Nothing here talks to a real Galaxy; all results are examples.

Spec only Proposal cards with Run and Open in Galaxy, replaced cards, run status and read-only details. The user has to ask for every next step. Spec + proposed changes Opens on a recorded run played through to the end. Each change is tagged "proposed" with its number.

Proposed changes

  • Uploaded files are grouped into one collection.
  • A plan at the start, built from an installed workflow.
  • A "Next step" button when a run completes.
  • "Run it" does the same as the Run button.
  • A run's outputs are shown as one collection.
  • The assistant can preview outputs and say what they show.
  • Repeated blocks, such as DESeq2's groups, are filled from the chat.
