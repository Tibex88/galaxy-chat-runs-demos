# Galaxy chat runs demos

Clickable mock-ups for discussing how Galaxy tools run from a chat thread.

- `spec.html`: follows the "Galaxy Runs Through Chat" spec only.
- `proposed.html`: the same thread with our proposed changes, each tagged "proposed". It opens on a recorded run played through to the end; "Step through it yourself" restarts it.

Everything is static HTML with example data. Nothing connects to Galaxy or mcp-xp.

The source files live in the Galaxy workspace as `galaxy-chat-runs-demo.html` and `galaxy-chat-runs-proposed.html`; these copies add a page skeleton and navigation, and replace the Galaxy host with `galaxy.example.org`.
