Running Galaxy tools from a chat thread, with a plan

Same thread as the spec-only demo, with the changes we would propose. Everything marked proposed is not in the "Galaxy Runs Through Chat" spec.

  1. Files become a collection. Uploaded R1/R2 files are paired into one collection the tools can run over.
  2. A plan at the start. Built from an installed workflow that fits the request; the platform ticks steps off as runs complete.
  3. "Next step" button. Shown when a run completes. The platform already polls run status, so no run-ending webhook is needed.
  4. "Run it" is an action. It does exactly what the Run button does; it does not go to the assistant.
  5. Outputs grouped. A run over a collection shows one collection of outputs instead of one row per file.
  6. The assistant can preview outputs. A read-only tool lets it say what a result shows.
  7. Repeated blocks filled from the chat. DESeq2's groups come from the first message, so it runs from chat.
